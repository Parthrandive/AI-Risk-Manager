Every payment gets 100 milliseconds to be trusted, reviewed, or blocked.

Block too hard and honest shoppers churn. Ignore risk and chargebacks destroy gross margin. Flag everything and the fraud operations queue drowns. AI Risk Manager is a production triage gateway engineered to sit honestly inside this trade-off.

03 Diagnostic Discipline

The systemic leaks we audited and fixed.

Split Leakage
Naive Kaggle BenchmarkRandom k-fold shuffle allows future cardholder patterns to leak into the training partition.
Production FixStrict chronological quantile split verified via zero-timestamp overlap invariant.
Intra-Split Target Leakage
Naive Kaggle BenchmarkGlobal per-card mean encoding allows an early transaction to "see" future transaction amounts.
Production FixExpanding cumulative historical mean — strictly conditioned on prior activity up to t−1.
Cold-Start Boundary Flaw
Naive Kaggle BenchmarkVelocity state resets to zero at the test split boundary, blinding the model to ongoing attacks.
Production FixStreamingRiskState carries rolling velocity & recency continuously across the split barrier.
Temporal Decay Inversion
Naive Kaggle BenchmarkBlindly trusting opaque vendor features that exhibit transient correlation in Month 1.
Production FixMonth 1 $\to$ Month 5 audit identified 64 decaying/inverting raw vendor features; 100% of domain features held stable.
Empirical Reality Check — On synthetic benchmark data, linear models falsely outperformed tree ensembles. Once deployed on the authentic 590,540-transaction IEEE-CIS dataset, XGBoost dominated by +0.33 PR-AUC, proving the necessity of real payment distributions.

06 Negative Findings & Architecture Ablations

The "What Didn't Work" registry that proves rigor.

01
Trimming to 20 "interpretable-only" features and dropping vendor fields
PR-AUC collapsed to 0.225 (-0.286 drop). Restored full 429 features and added an opaque-signal disclosure layer instead.
02
Relational Graph Embeddings (GraphSAGE 16-dim representation)
PR-AUC degraded from 0.5111 to 0.5047 (Information Subsumption). Streaming velocity features already captured graph topology.
03
Hardcoded scale_pos_weight = 28.87 class balancing
Severely distorted posterior probability calibration. Replaced with empirical cost-sensitive threshold grid search.
04
Static default classification threshold of 0.500
Arbitrary and un-costed. Replaced with asymmetric 3-tier gateway bounded by 3% analyst capacity and 90% precision.
05
Temporal Consistency Audit on all 429 features (Month 1 vs Month 5)
Identified 64 raw vendor V-features that decayed or inverted over time; 100% of domain velocity features passed stationarity checks.
